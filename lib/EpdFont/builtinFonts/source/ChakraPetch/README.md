# Chakra Petch Bold

Unmodified upstream font from [Google Fonts](https://github.com/google/fonts/tree/c011968d86a629939a4fd8b62a3b18549db0d855/ofl/chakrapetch), commit `c011968d86a629939a4fd8b62a3b18549db0d855`.

Copyright 2018 The Chakra Petch Project Authors. Licensed under the SIL Open Font License 1.1; see [OFL.txt](OFL.txt).

The Pomodoro countdown uses only digits and a colon. Regenerate its monochrome subset with `python scripts/generate_countdown_font.py`. The generated bitmap uses centered tabular digit advances for stable countdown alignment. The source font is not bundled into firmware.
